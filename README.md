# GoRide - Ride Sharing App

A ride-hailing web app in the style of Rapido, Ola and Uber. Runs in any browser, no install needed.

**What it does**
- City map with real shortest-path routing: the driver and your trip follow the actual roads
- Bike, Auto, Mini, Sedan and Pool with fares based on the route distance, demand pricing and coupons (GORIDE20, WELCOME50)
- Driver matching, PIN to start the trip, live trip with fare and distance left
- Pay by UPI, Card, Cash or Wallet, add a tip, see the fare breakdown, rate the driver
- Ride history and wallet balance saved in the browser

Drivers, map and fares are simulated. To change fares, edit the `T` list in the script in `index.html`.

**Run it:** open `index.html`, or turn on GitHub Pages for this repo.
